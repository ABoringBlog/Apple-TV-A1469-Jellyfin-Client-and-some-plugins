# CloudTune / 云律音乐 branding

The public name **CloudTune / 云律音乐** and the public cloud + music-note + sound-wave icon were intentionally created for this project after the user asked ChatGPT to invent a replacement identity.

They are **not** official NetEase Cloud Music names, logos, icons, or artwork. The goal is to avoid copying or presenting official brand assets and to reduce the chance that users confuse this independent project with an official client.

This branding choice does **not** guarantee that the project has no legal, trademark, API, or service-terms risk. References to NetEase Cloud Music remain only where technically necessary to explain account login, compatibility, and the third-party service being accessed.

This project is independent and is not affiliated with, endorsed by, or sponsored by NetEase.
